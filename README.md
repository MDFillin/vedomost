# Ведомость — бот для отметки посещаемости в Telegram

Бот для старосты. В назначенные дни и время он присылает в общий чат группы сообщение
с текущей датой («📅 Среда, 30 сентября 2026») и кнопкой **«🚫 Пропускаю»**.

**Нажимают только те, кого не будет.** Все остальные студенты из списка группы
считаются присутствовавшими — им ничего делать не нужно. Нажавший видит «🚫 Записал:
вы пропускаете занятие 30.09». Если планы поменялись, можно нажать кнопку ещё раз и
подтвердить — пропуск отменится.

> ⚠️ Раз присутствие теперь «по умолчанию», важно, чтобы в списке группы были **все**
> студенты: кого нет в списке, того нет и в ведомости. Лучше всего включить
> автосчитывание участников чата (ключи `API_ID`/`API_HASH`, см. ниже).

Под ней есть вторая кнопка — **«😷 Я болею»**. Она открывает личный чат с ботом, где
студент выбирает в календаре первый и последний день больничного (или пишет даты текстом:
`28.09-02.10`). Больничный сразу попадает в ведомость: в эти дни студент считается
не прогульщиком, а болеющим, староста получает уведомление. Свои больничные студент
видит в личке с ботом и может удалить ошибочный.

В личной переписке с ботом у старосты есть админ-панель:

- 📊 **Посещаемость по месяцам** — сводка по каждому месяцу (занятий, % посещаемости,
  больничные, «н», кто больше всех пропускает), внутри — дни; для каждого дня видно,
  **кто был, кто пропускает (и когда нажал) и кто на больничном**. Можно вручную
  поставить или снять пропуск, закрыть или снова открыть отметку, удалить занятие.
- 👥 **Студенты и сводка** — посещаемость каждого (например, `18/20 (90%) 😷2`), пропуски
  и больничные по датам, добавление больничного за студента, переименование, исключение.
- 😷 **Больничные** — все текущие и недавние больничные, удаление ошибочных.
- 🗓 **Расписание** — дни недели и время (можно несколько пар в день), разовые даты,
  пропуски (праздники, каникулы — одной строкой `29.12.2026-11.01.2027`).
- ⚙️ **Настройки**:
  - 📝 **текст сообщения** — заголовок, текст и надпись на кнопке, с форматированием и
    подстановками `{дата}`, `{день}`, `{время}`, `{до}`, предпросмотр;
  - 🔁 **режим** — отметка **на каждой паре** или **раз в день**;
  - ⏳ **сколько активна кнопка** — N минут после отправки, **до определённого времени**
    (например, до 10:30), до конца дня или пока не закроете вручную;
  - 🛡 **защита от накрутки** (см. ниже);
  - счётчик и список отметившихся в группе, закрепление, формат имён, сортировка,
    часовой пояс, итог старосте после закрытия отметки.
- 📤 **Отправить отметку сейчас** — внеплановая отметка одной кнопкой.
- 📥 **Ведомость в Excel** (.xlsx) — в формате бумажного журнала: лист на каждый месяц,
  в первой строке название группы и дни недели, во второй — месяц и числа, дальше ФИО;
  `н` — не был, `б` — болел (с заливкой), пустая клетка — был, в конце `ИТОГО` —
  формула с числом «н». Можно выгрузить один месяц или все сразу. Отдельный лист —
  список всех больничных. Название группы берётся из названия чата и меняется
  в настройках.

### 👥 Автоматический список группы
Когда староста добавляет бота в чат, бот **сам привязывается** к нему и **считывает всех
участников** — они сразу становятся списком группы. Перед каждой отметкой состав
сверяется заново: новые участники добавляются, вышедшие из чата перестают учитываться.
Кнопка «🔄 Считать участников чата» в разделе 👥 Студенты делает то же вручную.

Для полного считывания нужны ключи `API_ID` и `API_HASH` (бесплатно, 2 минуты — см. ниже):
обычный Bot API не отдаёт список участников, поэтому бот использует MTProto от своего имени.
Без ключей бот всё равно пополняет список: добавляет администраторов чата, всех, кто
заходит в чат или пишет в него, и всех, кто нажмёт кнопку или «🙋 Я в группе».

### 🛡 Защита от накрутки
- Отметиться можно **один раз**; повторное нажатие не засчитывается.
- **Только участники чата**: при нажатии бот проверяет у Telegram, что человек состоит
  в группе. Посторонние отметиться не могут и в список не попадают.
- **Пересылка не работает**: сообщение отправляется с запретом пересылки и копирования,
  а нажатия с копий в других чатах бот отклоняет в любом случае.
- **Только из списка** (по желанию): отмечаться могут только студенты из списка.
- Исключённые старостой и боты отметиться не могут.

Физически нажать кнопку с чужого телефона, конечно, по-прежнему можно — это защита от
посторонних и от накрутки через пересылку, а не от «друг отметил за меня».

> ℹ️ Сообщение в группе одно на всех, поэтому Telegram не может убрать кнопку только у
> одного человека. Защита от повторного нажатия работает на стороне бота: второй раз
> отметка не засчитывается, а человек видит «Вы уже отметились». После окончания
> времени на отметку кнопка исчезает у всех.

## Запуск за 5 минут

### 1. Создайте бота
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, придумайте имя. Скопируйте **токен**.
2. Узнайте свой Telegram ID — напишите [@userinfobot](https://t.me/userinfobot).

### 2. Получите API_ID и API_HASH (для автосчитывания участников)
1. Зайдите на [my.telegram.org](https://my.telegram.org) под своим номером.
2. **API development tools** → заполните название (любое, например `vedomost`) → **Create**.
3. Скопируйте `App api_id` и `App api_hash`.

Ключи используются только для того, чтобы бот от своего имени получил список участников
чата. Ваш аккаунт бот не использует. Шаг можно пропустить — тогда список будет
собираться постепенно (см. выше).

### 3. Настройте
```bash
cp .env.example .env
# впишите BOT_TOKEN, ADMIN_IDS (ваш ID; помощников можно через запятую),
# API_ID и API_HASH
```

### 4. Запустите
Через Docker (рекомендуется для сервера):
```bash
docker compose up -d --build
```
Или напрямую (Python 3.11+):
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Бот должен работать постоянно, чтобы отправлять сообщения по расписанию — запускайте
его на сервере (VPS, домашний компьютер/Raspberry Pi, любой хостинг с Python или Docker).
База данных хранится в файле `data/vedomost.db` — его достаточно бэкапить.

### 5. Подключите к группе
1. Напишите боту в личку `/start` — откроется панель старосты.
2. **Сами** добавьте бота в общий чат группы. Бот привяжется автоматически, считает
   участников и пришлёт вам в личку отчёт. (Если бот уже был в чате — отправьте там `/bind`.)
3. Рекомендуется сделать бота **администратором** чата (достаточно прав без галочек):
   так он будет видеть вход и выход участников и сможет закреплять сообщения.
4. В панели: **🗓 Расписание → ➕ Дни недели**, выберите дни и отправьте время, например
   `09:00` или `09:00 13:40`.
5. В **⚙️ Настройки** выберите режим (на каждой паре / раз в день), до какого времени
   активна кнопка и отредактируйте текст сообщения.

### Сообщество с несколькими чатами или чат с темами
Бот пишет **только в один** привязанный чат (или одну тему) и игнорирует остальные:
кнопки, сообщения и участники других чатов ни на что не влияют.
- **Несколько отдельных чатов**: отправьте `/bind` в том чате, куда нужны отметки.
  Добавление бота в другие чаты привязку не меняет — только новая команда `/bind`.
- **Чат с темами (форум)**: откройте нужную тему (например, «Посещаемость») и отправьте
  `/bind` прямо в ней — отметки будут приходить только в эту тему. `/bind` в теме
  «Общее» вернёт отправку в основную ленту.

Куда сейчас приходят отметки, видно в главном меню панели старосты.

## Резервные копии
Бот сам присылает старосте в личку резервную копию — по умолчанию **каждый день в 23:00**
(в панели: 💾 Резервные копии — можно раз в неделю, другое время, выключить или сделать
копию сразу). Копия — два файла:
- `vedomost_backup_…db` — вся база: студенты, занятия, пропуски, больничные, настройки;
- `vedomost_….xlsx` — ведомость, чтобы данные можно было прочитать и без бота.

**Восстановление:** 💾 Резервные копии → ♻️ Восстановить → отправить боту файл `.db`.
Бот покажет, что в файле, и перед заменой пришлёт копию текущих данных.

**Переезд на новый сервер:** установите бота по инструкции выше с тем же `.env`, напишите
ему `/start` и восстановите последнюю копию — вся история вернётся.

## Команды
| Где | Команда | Что делает |
|---|---|---|
| Личка | `/menu`, `/start` | Панель старосты |
| Личка | `/help` | Инструкция |
| Личка | `/cancel` | Отменить ввод |
| Группа | `/bind` | Привязать чат (только староста) |
| Группа | `/unbind` | Отвязать чат |

## Как это устроено
- `bot/stats.py` — единое правило «был / пропустил / болел».
- `bot/handlers/group.py` — кнопка «Пропускаю» и проверки доступа, автопривязка, вход/выход
  участников, `/bind`.
- `bot/handlers/sick.py` — больничный: календарь и ввод дат в личке.
- `bot/members.py` — считывание участников чата и проверка членства.
- `bot/handlers/admin.py` — админ-панель.
- `bot/scheduler.py` — каждые 20 секунд проверяет расписание и закрывает просроченные
  отметки. Если бот был выключен в момент отправки, он отправит сообщение, только если
  опоздал не более чем на 15 минут (чтобы не слать «вчерашние» отметки).
- `bot/db.py` — SQLite. Отметка записывается атомарно, двойное нажатие не создаст дубль.

## Тесты
```bash
pip install -r requirements-dev.txt
pytest
```
Тесты работают без сети: Telegram API подменяется фейковой сессией, а один из тестов
прокликивает все кнопки админ-панели.
