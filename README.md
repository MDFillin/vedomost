# Ведомость — бот для отметки посещаемости в Telegram

Бот для старосты. В назначенные дни и время он присылает в общий чат группы сообщение
с датой и большой зелёной кнопкой **«✅ Я был»**. Каждый присутствующий нажимает кнопку —
бот показывает ему всплывающее окно «✅ Присутствие записано!», а повторное нажатие
отвечает «Вы уже отметились», второй раз отметка не засчитывается.

В личной переписке с ботом у старосты есть админ-панель:

- 📊 **Занятия** — список всех дней; для каждого видно, **кто был (и во сколько отметился)
  и кого не было**. Можно вручную поставить/снять отметку, закрыть или снова открыть
  отметку, удалить занятие.
- 👥 **Студенты и сводка** — посещаемость каждого (например, `18/20 (90%)`), список
  пропусков по датам, переименование, исключение из списка.
- 🗓 **Расписание** — дни недели и время (можно несколько пар в день), разовые даты,
  пропуски (праздники, каникулы — одной строкой `29.12.2026-11.01.2027`).
- ⚙️ **Настройки** — счётчик и список отметившихся в группе, закрепление сообщения,
  сколько минут открыта отметка, формат имён, сортировка, заголовок и текст кнопки,
  часовой пояс, итог старосте после закрытия отметки.
- 📤 **Отправить отметку сейчас** — внеплановая отметка одной кнопкой.
- 📥 **Выгрузка в CSV** — таблица «студент × дата» (`+` / `н`), открывается в Excel.

> ℹ️ Сообщение в группе одно на всех, поэтому Telegram не может убрать кнопку только у
> одного человека. Защита от повторного нажатия работает на стороне бота: второй раз
> отметка не засчитывается, а человек видит «Вы уже отметились». После окончания
> времени на отметку кнопка исчезает у всех.

## Запуск за 5 минут

### 1. Создайте бота
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot`, придумайте имя. Скопируйте **токен**.
2. Узнайте свой Telegram ID — напишите [@userinfobot](https://t.me/userinfobot).

### 2. Настройте
```bash
cp .env.example .env
# впишите BOT_TOKEN и ADMIN_IDS (ваш ID; помощников можно через запятую)
```

### 3. Запустите
Через Docker (рекомендуется для сервера):
```bash
docker compose up -d --build
```
Или напрямую (Python 3.11+):
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Бот должен работать постоянно, чтобы отправлять сообщения по расписанию — запускайте
его на сервере (VPS, домашний компьютер/Raspberry Pi, любой хостинг с Python или Docker).
База данных хранится в файле `data/vedomost.db` — его достаточно бэкапить.

### 4. Подключите к группе
1. Напишите боту в личку `/start` — откроется панель старосты.
2. Добавьте бота в общий чат группы.
3. Отправьте в этом чате `/bind` — бот запомнит чат (сработает только от старосты).
4. В панели: **🗓 Расписание → ➕ Дни недели**, выберите дни и отправьте время, например
   `09:00` или `09:00 13:40`.
5. Чтобы в статистике «кого не было» сразу были все, нажмите
   **👥 Студенты → 📨 Регистрация в группе** — каждый нажмёт «🙋 Я в группе».
   Кроме того, студент автоматически попадает в список при первом нажатии «Я был».

Если включено «Закреплять сообщение», дайте боту в группе права администратора
на закрепление сообщений. Для всего остального права админа не нужны.

## Команды
| Где | Команда | Что делает |
|---|---|---|
| Личка | `/menu`, `/start` | Панель старосты |
| Личка | `/help` | Инструкция |
| Личка | `/cancel` | Отменить ввод |
| Группа | `/bind` | Привязать чат (только староста) |
| Группа | `/unbind` | Отвязать чат |

## Как это устроено
- `bot/handlers/group.py` — кнопка «Я был», регистрация, `/bind`.
- `bot/handlers/admin.py` — админ-панель.
- `bot/scheduler.py` — каждые 20 секунд проверяет расписание и закрывает просроченные
  отметки. Если бот был выключен в момент отправки, он отправит сообщение, только если
  опоздал не более чем на 15 минут (чтобы не слать «вчерашние» отметки).
- `bot/db.py` — SQLite. Отметка записывается атомарно, двойное нажатие не создаст дубль.

## Тесты
```bash
pip install -r requirements-dev.txt
pytest
```
Тесты работают без сети: Telegram API подменяется фейковой сессией, а один из тестов
прокликивает все кнопки админ-панели.
