# Ведомость — Telegram-бот посещаемости для старосты

Весь интерфейс бота и общение с владельцем — **на русском**. Владелец — староста,
не программист: объяснять просто, команды давать готовыми к копированию.

История разработки и принятые решения — в `docs/HANDOFF.md`. Прочитай его в начале
новой сессии.

## Как устроено
- Python 3.11+, aiogram 3, SQLite (`data/vedomost.db`), Telethon (необязательно,
  для чтения участников чата), openpyxl (Excel).
- `bot/__main__.py` — запуск: роутеры, команды, фоновый планировщик.
- `bot/db.py` — схема, миграции (`Database.upgrade()` → `_migrate()`), все запросы.
- `bot/stats.py` — **единое правило статуса**: больничный > пропуск > присутствовал.
  Отмечаются только отсутствующие (кнопка «🚫 Пропускаю»); все студенты из списка,
  кто ничего не нажал, считаются присутствовавшими. Не дублируй эту логику — зови
  `session_statuses` / `student_statuses` / `totals`.
- `bot/service.py` — текст и кнопки сообщения в группе, отправка/закрытие отметок,
  расписание (`due_slots`, `compute_close_at`).
- `bot/scheduler.py` — тик раз в 20 с: отправка по расписанию, закрытие, бэкап.
- `bot/handlers/group.py` — чат группы: «Пропускаю» (повторное нажатие + подтверждение
  отменяет пропуск), «Я болею», `/bind` (в т.ч. в теме форума), вход/выход участников,
  проверки доступа.
- `bot/handlers/sick.py` — больничный в личке: календарь или даты текстом.
- `bot/handlers/admin.py` — панель старосты (только `ADMIN_IDS`).
  Префиксы callback: `a:` админка, `sk:` больничный, `skip:`/`sick:`/`register` группа.
- `bot/handlers/errors.py` — регистрируется на `dp.errors`, отвечает на любую упавшую
  кнопку, чтобы она не «крутилась».
- `bot/excel.py` — ведомость в формате бумажного журнала (лист на месяц, «н»/«б»,
  ИТОГО = `COUNTIFS(...,"Н")`).
- `bot/backup.py` — резервные копии в личку старосте и восстановление.

## Проверки перед коммитом
```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt pyflakes
python -m pyflakes bot tests
pytest -q
```
Тесты работают без сети: Telegram подменён `FakeSession` в `tests/test_bot.py`;
`test_click_every_admin_button` прокликивает всю админку.

## Деплой (на сервере владельца)
Бот работает в Docker из `/opt/vedomost`:
```bash
git pull && docker compose up -d --build
docker compose logs --tail 50
```
Данные — в `data/` (volume). Секреты — в `.env` (`BOT_TOKEN`, `ADMIN_IDS`, `TIMEZONE`,
`API_ID`, `API_HASH`). **Никогда не выводи содержимое `.env` и не коммить его.**
Перед рискованными действиями с данными попроси владельца нажать
«💾 Резервные копии → 📤 Сделать копию сейчас».

## Правила
- Схему БД меняй только через миграции в `_migrate()` — у владельца живые данные.
- Новые настройки — в `DEFAULT_SETTINGS` (досоздаются при запуске).
- Тексты для Telegram — HTML (`parse_mode=HTML`), пользовательский ввод экранируй `esc()`.
